# IEEE-CIS Source Drop Folder

Place licensed/downloaded IEEE-CIS transaction CSV files here. Official source: https://www.kaggle.com/competitions/ieee-fraud-detection

The adapter uses transaction-level fields such as `TransactionID`, `isFraud`, `TransactionDT`, `TransactionAmt`, `ProductCD`, and card/address-derived fields. It does not create ATM locations, complaint IDs, destinations, or cash-out ground truth.
