# Dataset Sources

This file is the source-focused companion to [DATA_SOURCES.md](DATA_SOURCES.md). It records the public sources used by the data foundation and their boundaries.

## Public sources

### IEEE-CIS Fraud Detection

- URL: https://www.kaggle.com/competitions/ieee-fraud-detection
- Publisher: Vesta Corporation and IEEE-CIS
- Actual fields used by the adapter: TransactionID, isFraud, TransactionDT, TransactionAmt, ProductCD, card identifiers, address-derived fields, and engineered transaction fields
- Provides: transaction behaviour, fraud labels, amounts, and relative timestamps
- Does not provide: NCRP complaints, Indian banking records, ATM withdrawal locations, or direct cash-out ground truth
- Access: Kaggle competition terms

### Credit Card Fraud Detection

- URL: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- Publisher: Worldline and Universite Libre de Bruxelles
- Actual fields: Time, V1-V28, Amount, Class
- Provides: anonymized transaction behaviour, amounts, time, and fraud labels
- Does not provide: account relationships, complaint IDs, ATM locations, or Indian banking data
- Access: Kaggle dataset terms

### OpenStreetMap

- URL: https://www.openstreetmap.org
- Publisher: OpenStreetMap contributors
- Actual fields: map geometry, coordinates, roads, POIs, and place labels
- Provides: geographic context and possible mapped ATM/POS points
- Does not provide: transaction, fraud, complaint, account, or withdrawal telemetry
- Access: Open Database License (ODbL)

## Synthetic and derived layers

The ML workflow is generated by `data/pipeline/generateSyntheticML.mjs`. It creates synthetic complaint/case relationships, transaction chains, withdrawal ground truth, ATM candidates, and feature rows. Derived fields are documented in [FEATURE_SCHEMA.md](FEATURE_SCHEMA.md). None of these records are claimed to be live NCRP, Indian banking, CFCFRMS, or ATM telemetry.
